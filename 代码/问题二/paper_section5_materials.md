## 5. 问题二：中长期封锁下的油价调节与平衡点预测模型

本节研究霍尔木兹海峡封锁持续至 90-180 天时国际原油价格的中长期调节过程。与短期阶段不同，中长期油价不再主要由恐慌情绪驱动，而是由替代供给释放、长期需求价格弹性、战略储备与商业库存消耗、运输瓶颈约束共同决定。为刻画上述机制，本文构建“供需均衡价格—库存风险溢价—价格惯性调整”模型，并在乐观、基准、悲观三种情景下预测油价路径及第 180 天价格平衡点。

## 5.1 问题二分析

在封锁进入中长期阶段后，市场已逐步消化初始冲击，油价变化主要体现为供需系统重新寻找平衡点。若其他产油国增产和绕道运输能力释放较快，则有效供给缺口收窄，油价可能回落；若运输瓶颈持续、库存快速消耗，则库存缓冲能力下降，并产生额外风险溢价，油价可能出现跳变式上涨。

## 5.2 中长期供需调节模型构建

设战前全球原油供给和需求均为 `100` 百万桶/日，封锁造成的中长期有效供应损失为 `L`。第 `t` 天非库存供给由剩余基础供给、绕道运输、其他产油国增产和战略储备释放共同组成：

```text
S_t^0 = Q0 - L + B_t + G_t + R_t
```

其中，`B_t` 表示绕道运输能力，`G_t` 表示其他产油国增产，`R_t` 表示战略储备释放。商业库存释放为：

```text
C_t = min(Cap_t, I_t, max(0, D0 - S_t^0))
I_{t+1} = I_t - C_t
```

有效供给为：

```text
S_t = S_t^0 + C_t
```

在长期需求价格弹性 `epsilon` 下，需求函数为：

```text
D(P) = D0 * (P/P0)^epsilon
```

令 `D(P_t^*) = S_t`，得到第 `t` 天供需均衡价格：

```text
P_t^* = P0 * (S_t / D0)^(1/epsilon)
```

库存不足时引入风险溢价：

```text
Risk_t = 0,                         I_t >= Imin
Risk_t = Rmax * (1 - I_t/Imin)^2,   I_t < Imin
```

最终价格按惯性调整：

```text
P_{t+1} = P_t + lambda * (P_t^* + Risk_t - P_t)
```

## 5.2.1 其他产油国增产响应建模

其他产油国增产无法瞬时完成，受钻井、调度、港口、油轮和管线能力约束。因此本文将增产响应设为随时间递增的线性爬坡函数：

```text
G_t = G_90 + (G_180 - G_90) * (t - 90) / 90,  90 <= t <= 180
```

基准情景下，其他产油国增产从第90天的 1.0 百万桶/日逐步提高至第180天的 4.5 百万桶/日。与此同时，绕道运输能力从 2.4 百万桶/日提高至 3.0 百万桶/日，但受沙特、阿联酋管道与非霍尔木兹港口能力限制，不能无限扩大。

## 5.3 油价平衡点与跳变风险模型

在完成中长期供需调节过程建模后，需要进一步回答两个关键问题：第一，在封锁持续至第180天时，油价会收敛到哪个中长期平衡点；第二，当库存缓冲能力接近耗尽时，油价是否会从平滑调整转为跳变式上涨。为此，本文在长期需求价格弹性模型基础上，引入库存阈值风险溢价项，将中长期油价分解为“供需均衡价”和“库存风险溢价”两部分。

记第 `t` 天理论均衡价为 `P_t^*`，库存风险溢价为 `Risk_t`，则市场目标价格为：

```text
P_t^{target} = P_t^* + Risk_t
```

实际价格考虑市场调整惯性：

```text
P_{t+1} = P_t + lambda * (P_t^{target} - P_t)
```

其中 `lambda=0.16` 表示价格向目标价收敛的速度。该设定能够同时刻画正常情况下的平滑收敛，以及库存跌破阈值后的非线性上行风险。

### 5.3.1 中长期供需均衡条件

中长期阶段，短期恐慌需求逐渐消退，需求端主要由价格弹性调节。本文设长期需求函数为：

```text
D(P) = D0 * (P/P0)^epsilon
```

其中 `D0=100` 百万桶/日，`P0=75` 美元/桶，长期需求价格弹性 `epsilon=-0.18`。第 `t` 天有效供给为：

```text
S_t = Q0 - L + B_t + G_t + R_t + C_t
```

各符号含义如下：

- `Q0`：战前全球供给；
- `L`：霍尔木兹封锁造成的有效供应损失；
- `B_t`：绕道运输能力；
- `G_t`：其他产油国增产响应；
- `R_t`：战略储备释放；
- `C_t`：商业库存释放。

供需均衡条件为：

```text
D(P_t^*) = S_t
```

即：

```text
D0 * (P_t^*/P0)^epsilon = S_t
```

该条件表示：当供给减少时，油价必须上升，使需求沿长期需求曲线收缩，直到需求量等于有效供给量。

### 5.3.2 价格平衡点求解

由供需均衡条件：

```text
D0 * (P_t^*/P0)^epsilon = S_t
```

可解得第 `t` 天理论平衡价：

```text
P_t^* = P0 * (S_t/D0)^(1/epsilon)
```

由于 `epsilon<0`，当 `S_t/D0` 下降时，`P_t^*` 上升。这正好反映了原油需求缺乏弹性时，较小的供给缺口也可能造成较大的价格变化。

第180天三种情景的平衡点如下。

**表5-4 第180天供需均衡点求解结果**

| 情景 | 第180天有效供给 | 第180天剩余缺口 | 第180天理论平衡价 | 第180天实际预测价 | 解释 |
|---|---:|---:|---:|---:|---|
| 乐观情景 | 98.00 | 2.00 | 83.91 | 84.36 | 替代供给较强，油价回落 |
| 基准情景 | 94.00 | 6.00 | 105.77 | 105.62 | 价格基本收敛至均衡点 |
| 悲观情景 | 89.50 | 10.50 | 138.90 | 169.09 | 库存风险溢价推高实际价格 |

由表5-4可见，基准情景下第180天理论平衡价为 105.77 美元/桶，实际预测价为 105.62 美元/桶，两者非常接近，说明此时价格已基本完成中长期均衡调整。乐观情景下有效供给达到 98.00 百万桶/日，剩余缺口仅 2.00 百万桶/日，平衡价下降至 83.91 美元/桶。悲观情景下有效供给仅为 89.50 百万桶/日，理论平衡价上升至 138.90 美元/桶，但由于库存接近耗尽，实际预测价进一步升至 169.09 美元/桶。

因此，中长期油价平衡点不是单一数值，而是随封锁强度、替代供给释放和库存状态变化而变化。基准情景下可将中长期平衡区间判断为 105-106 美元/桶；若调节顺利，平衡点可回落至 80-90 美元/桶；若供应修复不足且库存接近枯竭，则价格可能上行至 160-170 美元/桶。

### 5.3.3 库存阈值与价格跳变风险判断

库存具有缓冲供需缺口的作用，但库存并非无限。当商业库存高于安全阈值时，市场认为仍有足够缓冲能力，风险溢价为零；当库存低于阈值后，市场开始担心后续无法继续释放库存补足供应缺口，油价中会计入额外风险溢价。

本文设商业库存风险阈值为：

```text
I_min = 90
```

库存风险溢价函数为：

```text
Risk_t = 0,                         I_t >= I_min
Risk_t = Rmax * (1 - I_t/I_min)^2,  I_t < I_min
```

该函数具有两个特点：第一，当库存高于阈值时，风险溢价为零，价格主要由供需均衡决定；第二，当库存低于阈值时，风险溢价随库存下降非线性增加，从而刻画库存耗尽前市场预期突然恶化造成的价格跳变。

**表5-5 库存阈值与跳变风险判断**

| 情景 | 是否跌破库存阈值 | 首次跌破阈值天数 | 第180天商业库存 | 第180天风险溢价 | 跳变风险判断 |
|---|---|---:|---:|---:|---|
| 乐观情景 | 否 | - | 276.25 | 0.00 | 无明显跳变风险 |
| 基准情景 | 否 | - | 241.25 | 0.00 | 无明显跳变风险 |
| 悲观情景 | 是 | 第111天 | 16.25 | 34.45 | 存在显著跳变风险 |

由表5-5可知，乐观和基准情景下，第180天商业库存仍分别为 276.25 和 241.25 百万桶，高于 90 百万桶的风险阈值，因此库存风险溢价为 0，油价主要围绕供需均衡价平滑调整。悲观情景下，商业库存于第111天跌破阈值，第180天仅剩 16.25 百万桶，风险溢价达到 34.45 美元/桶。此时价格不再仅由当期供需缺口决定，而会叠加库存枯竭预期，导致油价从理论平衡价 138.90 美元/桶跳升至实际预测价 169.09 美元/桶。

因此，判断中长期油价是否出现跳变，关键不只在于供应缺口大小，还在于库存是否跌破安全阈值。只要库存仍高于阈值，油价更可能表现为向均衡点缓慢收敛；一旦库存低于阈值且供应缺口仍未修复，价格会进入“供需短缺 + 风险溢价”叠加阶段，形成非线性上行。
