# 问题1：短期冲击模型（0-90天）规划

## 1. 任务目标

围绕题目中的第一个问题，建立一个 **0-90天日度尺度的国际原油价格短期冲击模型**，用来解释并模拟 2026 年 2 月 28 日冲突爆发后，布伦特原油价格从战前约 75 美元/桶快速上升、随后在 90-110 美元区间震荡的演化过程。

本问题的核心不是只做一个价格拟合，而是要回答：

1. 为什么在“名义供应中断很大”的情况下，价格没有直接突破 200 美元/桶；
2. 短期内到底是哪些机制在共同决定价格路径；
3. 这些机制各自贡献了多少缓冲作用或放大作用。

最终希望得到一个 **可解释、可计算、可做情景分析** 的短期冲击模型。

---

## 2. 总体建模思路

采用 **“机制建模 + 数据校准” 的混合方案**：

1. 先根据题目描述构造日度供需平衡框架；
2. 将供应中断、战略储备释放、商业库存缓冲、绕道运输、恐慌性需求、价格弹性等因素写成随时间变化的函数；
3. 将这些因素汇总为“有效供需缺口”；
4. 用布伦特原油主力合约日度价格数据，对价格调整参数进行校准；
5. 通过情景模拟和敏感性分析，解释价格为何在短期内表现为“先剧烈上冲，再高位回落但不崩塌”。

建议把模型做成 **离散时间动态系统**，以第 \(t\) 天为状态更新节点。

---

## 3. 拟采用的模型框架

### 3.1 基础变量定义

以战前全球原油市场为基准：

- 基准供给：\(S_0 = 10000\) 万桶/日
- 基准需求：\(D_0 = 10000\) 万桶/日
- 基准价格：\(P_0\) 取事件前最后一个交易日价格，优先用 2026/2/27 的收盘价

定义第 \(t\) 天的关键变量：

- \(L_t\)：海峡封锁导致的原油供应损失
- \(R_t\)：战略储备释放量
- \(C_t\)：商业库存释放量
- \(B_t\)：绕道运输恢复量
- \(F_t\)：恐慌性需求放大量
- \(E_t\)：价格弹性导致的需求回落量
- \(I_t\)：剩余商业库存
- \(P_t\)：第 \(t\) 天油价

### 3.2 供给端结构

将有效供给写为：

\[
S_t = S_0 - L_t + R_t + C_t + B_t
\]

其中：

- \(L_t\) 在第 0 天后立即上升到高位，可先按 1400-1800 万桶/日设定；
- \(R_t\) 具有启动时滞和释放上限；
- \(C_t\) 受库存总量和单日最大释放速度约束；
- \(B_t\) 在 7-30 天后逐步启动，并在 300 万桶/日附近达到上限。

### 3.3 需求端结构

将有效需求写为：

\[
D_t = D_0 \cdot (1 + F_t)\cdot \left(\frac{P_t}{P_0}\right)^{\varepsilon}
\]

其中：

- \(F_t\) 表示短期恐慌性需求扰动，前 7-14 天显著，之后逐步衰减；
- \(\varepsilon = -0.05\) 为短期需求价格弹性；
- 若后续拟合发现仅靠该结构不足以解释价格回落，可加入“真实需求破坏”项作为扩展。

### 3.4 价格调整机制

优先采用比原题更稳定的 **相对缺口驱动模型**，避免量纲不一致：

\[
P_{t+1} = P_t + \beta_1 \frac{D_t - S_t}{S_0} P_t + \beta_2 F_t + \beta_3 \Omega_t
\]

其中：

- \(\beta_1\)：供需缺口对价格的传导强度；
- \(\beta_2\)：恐慌情绪对价格的额外推升强度；
- \(\Omega_t\)：库存紧张度或市场脆弱度指标，可选做增强项；
- 若模型复杂度需要控制，也可先用简化版本：

\[
P_{t+1} = P_t + \beta \left(D_t - S_t\right)
\]

然后在论文中说明其局限，并用归一化形式作为改进模型。

## 4. 数据使用计划

## 4.1 题目给定数据

当前可直接使用：

- 题面给出的结构性参数：
  - 供应中断量 1400-1800 万桶/日
  - 战略储备释放上限 200-700 万桶/日
  - 商业库存初值 5.8 亿桶
  - 绕道运输上限 300 万桶/日，启动 7-30 天
  - 恐慌需求系数 1.1-1.2，持续 1-2 周
  - 短期需求价格弹性 -0.05
- 附件数据：[附件1.布伦特原油期货主力合约价格数据.csv](<D:\codespace\mathematical-modeling\附件1.布伦特原油期货主力合约价格数据.csv>)

## 4.2 附件数据处理步骤

CSV 字段为：

- `time`
- `preClose`
- `open`
- `high`
- `low`
- `close`

计划对该数据做如下处理：

1. 提取 2026/2/27 至 2026/6/1 附近的事件窗口；
2. 使用 `close` 作为每日结算价格序列；
3. 将 2026/2/27 作为战前基准日；
4. 将 2026/2/28 记为冲突爆发第 0 天；
5. 由于期货数据是交易日数据，需说明“模型按自然日推演，观测按交易日校准”的处理原则：
   - 方案A：只在交易日比较模型与实际价格；
   - 方案B：自然日连续模拟，非交易日价格以前值填充；
6. 统计事件窗中的关键特征：
   - 峰值价格及出现时间；
   - 峰值后回落速度；
   - 90-110 美元区间震荡特征；
   - 波动率变化。

推荐优先采用 **方案A**，因为附件本身是交易日序列，更容易和实证校准匹配。

## 5. 参数设定与校准计划

## 5.1 直接给定参数

以下参数可先由题面直接给定，再在敏感性分析中做区间扰动：

- 供应中断：1400、1600、1800 万桶/日三档
- 战略储备释放上限：200、450、700 万桶/日三档
- 战略储备启动延迟：3、7、10 天三档
- 商业库存初值：5.8 亿桶
- 商业库存单日释放上限：待校准
- 绕道运输启动时间：7、15、30 天三档
- 绕道运输上限：300 万桶/日
- 恐慌需求系数：1.10、1.15、1.20 三档
- 恐慌持续期：7、10、14 天三档
- 短期价格弹性：-0.05

## 5.2 需要拟合或反推的参数

重点校准以下参数：

- \(\beta_1\)：供需缺口传导系数
- \(\beta_2\)：恐慌情绪价格放大系数
- 商业库存单日释放速度上限
- 恐慌项衰减速度
- 绕道运输爬坡速度

## 5.3 校准原则

拟采用 **“先定结构、再调参数、最后做稳健性验证”** 的顺序：

1. 先让模型能够再现“快速冲高”；
2. 再让模型能够再现“4月底见顶”；
3. 最后让模型能够再现“5月回落至 90-100 美元附近”。

若单一参数集难以同时匹配全部特征，则采用：

- 分段参数；
- 或“恐慌情绪 + 库存缓冲”双机制解释。

## 6. 具体实施步骤

### 阶段1：题意整理与变量统一

目标：把题面叙述转成数学变量和约束关系。

任务：

1. 提炼短期模型必须包含的 6 个机制；
2. 明确每个机制是“状态变量、控制变量还是外生变量”；
3. 确定所有变量单位统一为“万桶/日”与“美元/桶”；
4. 画出变量关系图，避免后续公式混乱。

阶段产出：

- 变量表
- 参数表
- 模型结构草图

### 阶段2：价格数据清洗与事件窗截取

目标：得到可用于拟合的价格序列。

任务：

1. 读取附件 CSV；
2. 筛选 2026 年事件窗口；
3. 计算事件前基准价格；
4. 标记事件后关键节点：
   - 第一次跳涨；
   - 4 月底峰值；
   - 5 月下旬回落区间；
5. 计算简单统计量：
   - 日收益率；
   - 滚动波动率；
   - 峰值涨幅。

阶段产出：

- 清洗后的价格序列
- 事件窗统计表
- 价格走势图

### 阶段3：建立供需缺口动态方程

目标：写出日度供给、需求、库存、价格联动方程。

任务：

1. 设定 \(L_t\) 的基础路径；
2. 设定 \(R_t\) 的延迟启动和上限约束；
3. 设定 \(C_t\) 的库存递减与释放约束；
4. 设定 \(B_t\) 的延迟启动与渐进恢复；
5. 设定 \(F_t\) 的短期冲高与指数衰减；
6. 引入价格弹性项形成需求反馈；
7. 写出最终价格更新公式。

阶段产出：

- 完整数学模型
- 各子函数定义
- 参数含义说明

### 阶段4：参数校准与初步拟合

目标：让模型能复现实测价格的大致路径。

任务：

1. 选取待估参数；
2. 设定目标函数，例如最小化模型价格与实际价格的平方误差；
3. 在合理参数范围内做网格搜索或数值优化；
4. 记录最优参数组合；
5. 对比模型路径与实际价格路径。

阶段产出：

- 一组基准参数
- 拟合误差指标
- 实际值与模拟值对比图

### 阶段5：情景分析与机制解释

目标：回答“为什么没有涨到 200 美元/桶”。

任务：

1. 设计至少三种情景：
   - 无库存缓冲
   - 有库存缓冲但无绕道运输
   - 完整机制联动
2. 对比不同情景下的峰值价格与高位持续时间；
3. 分析各机制的边际贡献：
   - 战略储备压低了多少价格峰值；
   - 商业库存延缓了多少天的高位冲击；
   - 绕道运输对后半段回落贡献多少；
   - 恐慌需求使早期价格额外放大多少。

阶段产出：

- 情景对比表
- 机制分解图
- 对题目异常现象的定量解释

### 阶段6：稳健性与论文写作准备

目标：保证模型在比赛论文中能讲清楚、站得住。

任务：

1. 做敏感性分析：
   - 中断量变化；
   - 储备释放上限变化；
   - 恐慌需求强度变化；
   - 绕道启动时滞变化；
2. 检查模型是否出现不合理结果：
   - 价格爆炸；
   - 库存变为负数；
   - 需求为负；
3. 总结模型优点、局限和可扩展方向；
4. 准备论文中的图表、符号说明和结论表述。

阶段产出：

- 敏感性分析图表
- 模型优缺点总结
- 可直接写入论文的结果框架

## 7. 论文中建议重点回答的问题

在最终写作时，本题第一个问题建议重点回答以下几点：

1. **封锁造成的名义供给冲击到底有多大？**
2. **为什么实际有效供给冲击小于名义冲击？**
3. **库存释放和绕道运输分别提供了多少缓冲？**
4. **恐慌需求为什么会造成前期价格超调？**
5. **短期价格弹性为什么会让价格在高位后逐步回落？**
6. **哪些机制共同解释了“价格没有突破 200 美元/桶”的现象？**
